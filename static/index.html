哔哩哔哩 (Bilibili) 画质增强设置
B站官方对未登录访客仅开放 480P 画质。配置任意 B 站免费普通账号的 SESSDATA 即可解锁 1080P 高码率原画；配置大会员账号可解锁 4K/8K 超清。
第 1 步：在电脑浏览器打开并登录 bilibili.com；
第 2 步：按 F12（或右键“检查”），切换到 Application (应用程序) -> Cookies -> bilibili.com；
第 3 步：找到 SESSDATA 条目，复制其 Value 值粘贴到上方输入框保存即可。
凭证仅保存在您本地浏览器的 LocalStorage 中，仅用于向官方接口请求 1080P/4K 视频流，绝对安全。
